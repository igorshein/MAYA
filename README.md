# Майя Самчинская — лендинг психолога

Новый лендинг на основе структуры PSYLANDING (`old/`), адаптированный под Майю Самчинскую.

## Что внутри
- `index.html` — одностраничный лендинг
- `assets/style.css` — стили: тёплая крем-бежевая палитра, адаптив, анимации
- `assets/script.js` — меню-бургер, плавный скролл, reveal-анимации, валидация формы, модалка согласия, cookie-баннер
- `send.php` — обработчик формы: пишет заявку в `requests.json` и шлёт письмо (если настроена почта)
- `img/maya-dress.png`, `img/maya-sunset.png` — фото из `photo/` (обрезаны по границам непрозрачных пикселей)
- `img/favicon.svg` — фавикон

## Секции (структура как в PSYLANDING)
Навигация → Hero → Обо мне → «Знакомо ли вам это?» → Запросы → Как я работаю → Форматы → Контакты → Форма записи → Футер + cookie-баннер и модалка согласия на обработку ПД.

- Тексты: `text/text.txt` + текст с taplink.cc/your_future_psychologist
- Контакты: WhatsApp +7 924 245-42-43 (с taplink) + ссылка на taplink
- Референсы стиля: `ref/` (редакционный крем-бежевый стиль)

## Что заменить перед деплоем
1. В `send.php`: `MAIL_TO` (ваша почта для заявок) и `MAIL_FROM` (ящик на домене сайта) — пока стоят `CHANGE-ME@example.com`. Без настройки заявки всё равно сохраняются в `requests.json`.
2. Мета-теги: добавить `og:url`/`canonical`, когда известен домен.
3. Опубликовать страницу Политики конфиденциальности по требованиям 152-ФЗ (текст модалки — краткий).

## Локальный запуск
```bash
python -m http.server 8080
```
Открыть http://localhost:8080. Форма полноценно работает только на PHP-хостинге
(локально python-сервер не исполняет `send.php` — форма покажет техошибку, это ожидаемо).

## Деплой
Статика + PHP: залить `index.html`, `assets/`, `img/`, `send.php` на хостинг
(например, reg.ru — как в старом проекте `old/README.md`).
Файл `requests.json` создаётся автоматически при первой заявке и содержит
персональные данные — не публиковать и не коммитить.
